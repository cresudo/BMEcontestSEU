🚀 使用流程
----------------------------------------------------------------

【步骤 1】准备原始数据
将 Sleep-EDF 数据库的 EEG 数据文件和标签文件放入：
- EEG 数据：bme/data/raw/Sleep-EDF Database/
- 标签文件：bme/data/raw/标签文件/

【步骤 2】运行数据预处理
cd bme
python data_preprocessor.py

预处理完成后会在 data/processed/ 目录下生成：
- eeg_frames.npy (脑电帧数据)
- frame_labels.npy (睡眠阶段标签)

【步骤 3】训练模型（N1+R 双优化版本）
python model_training_n1_r_optimized.py

训练完成后会在 data/processed/model_n1_r_optimized/ 目录下生成：
- 随机森林模型 (.pkl)
- 标签编码器 (.pkl)
- 特征矩阵 (.npy)
- 特征重要性 (.csv)

🔧 核心优化策略
----------------------------------------------------------------
1. 数据增强
   - N1 期：2.5 倍增强（670 → 1,675 样本）
   - R 期：3.5 倍增强（225 → 787 样本）

2. 特征工程（48 维特征）
   - 基础特征：33 个（时域 19 个 + 频域 14 个）
   - N1 专属特征：θ/δ比值、α波衰减指数、σ波功率等
   - R 专属特征：锯齿波功率、β波功率比、α波占空比等

3. 类别平衡
   - SMOTE 过采样：所有类别平衡到 1,398 个训练样本

4. 模型优化
   - 随机森林：2,000 棵树，最大深度 50
   - 类别权重平衡

📝 文件说明
----------------------------------------------------------------
【代码文件】
- data_preprocessor.py：数据预处理核心代码
  * 文件匹配（基于正则表达式）
  * 0.5-45Hz 带通滤波
  * 30 秒分帧（3000 数据点/帧）
  * 标签解析和清洗

- model_training_n1_r_optimized.py：N1+R 双优化训练代码
  * 48 维特征提取
  * N1/R 数据增强
  * SMOTE 过采样
  * 随机森林训练和评估

【数据文件】
- eeg_frames.npy：预处理后的 EEG 数据，shape=(4806, 3000)
- frame_labels.npy：睡眠阶段标签，shape=(4806,)
- features_matrix_*.npy：特征矩阵，shape=(样本数，48)

【模型文件】
- sleep_stage_rf_model_*.pkl：训练好的随机森林模型
- label_encoder_*.pkl：标签编码器（睡眠阶段→数字编码）
- feature_importance_*.csv：特征重要性排名

【日志文件】
- preprocessing.log：预处理详细日志
- 训练输出：直接打印到控制台
